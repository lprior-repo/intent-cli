MAINTAINABILITY RATINGS
================================================================================

Adding new command: EASY (3/10)
  1. Add description to cli_text_constants.gleam (1 line)
  2. Add flags if needed to cli_flags.gleam
  3. Create command function in intent.gleam (10-50 LOC)
  4. Register with glint (1 line)
  Time: 15-30 minutes

Updating help text: TRIVIAL (1/10)
  1. Edit constant in cli_text_constants.gleam
  2. No code changes needed
  Time: 2-5 minutes

Adding flag builder: EASY (2/10)
  1. Add builder to cli_flags.gleam (5-10 LOC)
  2. Add description to cli_text_constants.gleam (1 line)
  3. Use in commands (1-2 LOC)
  Time: 5-10 minutes

Splitting at 4,000 LOC: MODERATE (5/10)
  1. Create subcategory modules
  2. Move related constants
  3. Update imports (50-75 lines)
  4. Run tests
  Time: 1-2 hours

================================================================================
INTEGRATION CHECKLIST FOR NEW COMMANDS
================================================================================

When adding new commands, follow this checklist:

Help & Documentation:
  ☐ Add cmd_<name>_desc to cli_text_constants.gleam
  ☐ Add <name>_extended_help with WHAT/WHY/WHEN sections
  ☐ Add to CLAUDE.md commands list

Flags & Configuration:
  ☐ Use flag builders from cli_flags.gleam
  ☐ Reference descriptions from cli_text_constants.gleam
  ☐ Load config with config.load_from_env() + merge_with_flags()

Error Handling & Output:
  ☐ Use error_handler.generic_error() for failures
  ☐ Use formatter_utils functions for output consistency
  ☐ Use emoji_constants (never hardcode emoji/strings)

Testing:
  ☐ Create test file with 5-10 test cases
  ☐ Test help text rendering
  ☐ Test flag validation
  ☐ Test error handling

Validation:
  ☐ All help text present and formatted
  ☐ Flag descriptions use cli_text_constants
  ☐ Error messages use error_handler
  ☐ Output uses formatter_utils or emoji_constants
  ☐ No hardcoded strings/emoji (only constants)
  ☐ gleam test passes
  ☐ intent help <command> renders correctly
