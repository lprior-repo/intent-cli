## [0.1.0] - 2026-01-17

### Features

- Initial release of Intent CLI
- EARS-based requirements parsing (6 patterns)
- KIRK contract analysis (quality, coverage, gaps, inversion, effects)
- Interactive interview mode for requirement gathering
- CUE-based specification format
- API testing and validation
- Bead (work item) generation from specifications
- Support for multiple profiles (api, cli, event, data, workflow, ui)

### Core Commands

- `intent check` - Run tests against API endpoints
- `intent validate` - Validate specification syntax
- `intent interview` - Interactive requirement gathering
- `intent quality` - Quality analysis across 5 dimensions
- `intent invert` - Identify potential failure cases
- `intent coverage` - HTTP method/status code coverage analysis
- `intent gaps` - Detect missing requirements
- `intent effects` - Analyze side effects and state changes
- `intent beads` - Generate atomic work items

### Analysis Features

- **Completeness:** Identify missing requirements and edge cases
- **Clarity:** Detect ambiguous language and vague requirements
- **Testability:** Ensure requirements are verifiable
- **Coverage:** Check HTTP method and status code coverage
- **Correctness:** Validate against best practices

### Mental Lattice Framework

- Inversion thinking (what could make this fail?)
- Second-order thinking (what happens after that?)
- Pre-mortem analysis (why did this fail?)
- Checklist approach (what did we miss?)
- Circle of competence (what's in scope?)
