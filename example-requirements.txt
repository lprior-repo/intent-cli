THE SYSTEM SHALL authenticate users with email and password

WHEN a user submits valid credentials THE SYSTEM SHALL return a 200 OK response with JWT token

WHEN a user submits invalid credentials THE SYSTEM SHALL return a 401 Unauthorized response

WHILE a session is active THE SYSTEM SHALL authorize requests using JWT token validation

WHERE the user has admin role THE SYSTEM SHALL grant access to admin endpoints

IF the request lacks a valid JWT token THEN THE SYSTEM SHALL NOT process protected requests

THE SYSTEM SHALL hash passwords using bcrypt before storing

WHEN a JWT token expires THE SYSTEM SHALL return a 401 Unauthorized response

THE SYSTEM SHALL log all authentication attempts for security auditing

IF the user attempts login more than 5 times in 10 minutes THEN THE SYSTEM SHALL NOT allow further attempts
