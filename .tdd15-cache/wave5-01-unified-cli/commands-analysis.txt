## Common Pattern from glint handlers:
1. Extract args from input.args (positional) or flags
2. Load spec using load_spec_for_mode(path, json_mode)
3. Call analyzer/processor module
4. Format response with json_output.success() or json_output.failure()
5. Output and halt with exit code

## For JSONL Router:
1. Extract args from Dynamic using dynamic.field()
2. Load spec using loader.load_spec_quiet() (always quiet for JSON)
3. Call same analyzer/processor module
4. Return JsonResponse directly (no halt/output needed)
